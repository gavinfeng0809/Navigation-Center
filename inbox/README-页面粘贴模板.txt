通知中心「页面粘贴」模板  （文件名以 README 开头，导入脚本会自动跳过它）
========================================================================

用途：如果你不想走 inbox 流程、想在页面上直接粘贴，就照下面格式写。
      这样一来，页面导入出来的效果 = 我现在给你做的效果（唯一的区别是谁来写摘要）。

在 通知中心 → 导入 → 粘贴文本 里，每条通知这样写（多条之间用**单独一行 ---** 分隔）：

------------------------------------------------------------------------
标签: 波士顿,流量监控,85%阈值,6条线路,路由调整
分类: 网络变更
级别: 重要

关键字：波士顿 / 流量监控 / 85%阈值 / 6条线路 / 路由调整

【一句话】钻石客户波士顿未来两周内部做路由调整，已为该客户 6 条线路配置“流量高于 85%”告警，收到告警需及时通知客户。

【要点】
1. 客户要求我司重点监控流量使用情况（因其未来两周内部路由调整）
2. 已完成：波士顿 6 条线路的流量 85% 阈值告警
3. 告警接收组：vipcustomeralert@example-corp.com
4. 行动项：收到告警如有异常，及时通知客户

【附件】无（原邮件未带附件，仅正文内嵌图片）

【查看原文】http://10.0.0.10:8091/originals/2026-09-15-79b3fbc9c91db3ea.html
------------------------------------------------------------------------


三条注意（都是实测踩过的坑）
----------------------------
1. **不要写「标题:」这一行**，尤其别写在最前面。
   服务端一看到「标题」就切进正文模式，后面的「标签/分类/级别」会被当成正文字符串吞掉、字段静默丢失。
   标题会自动取正文首行；一定要写标题，就把它放在头部字段的**最后一行**。

2. 「标签 / 分类 / 级别」必须写成 `键: 值` 才会进对应字段，才能在左侧筛选。
   正文里那行「关键字：…」只是给人看的，**不会**自动变成标签。
   （我用脚本回写时是两处都写：正文首行 + 标签字段。）

3. 「查看原文」那个链接，只有 public/originals/ 里确实存在那个页面时才打得开。
   **页面上传的邮件不会落盘**——服务端在内存里解析完就丢，原文件和附件实体都不保存，
   所以页面导入生成不了原文页，也就没有可下载的附件。


要在页面粘贴时，还需要注意
---------------------------
- 纯文本 / .txt / .md / .csv / .json / .xlsx / .eml 都能在页面上传；
  但 .eml 上传后原件不落盘，附件只留文件名、点不开。
- 想要「原文页 + 附件可下载」，就必须让文件落到磁盘上（丢 inbox/，走 tools/ 那两个脚本）。
- 「汇总 / 抓重点」这一步，页面导入**做不到**：服务端没有任何模型调用能力，
  它只会把邮件字段机械地填进库。摘要要么人写，要么由 Hermes 代写后回写。
