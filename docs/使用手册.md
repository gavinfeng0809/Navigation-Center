# 导航中心 · 重要通知中心

## 背景

重要通知平时散在两个地方：**企微群里刷过去就沉底，邮件躺在各自收件箱里。**
结果是同一件事反复被问——「上次那个割接通知是什么时候发的？」
「客户 IP 回收那个说的什么？」新人更是完全查不到历史。

这个系统就是为此建的：**把企微和邮件里的重要通知集中收进来，谁发都能归档，谁都能查。**
重要通知中心是核心模块；导航中心是顺带把内部系统入口也收在同一处。

> **一句话**：重要通知的集合系统 —— 企微群里 @ 一下机器人、或上传邮件，
> 通知就归档入库；其他人随时在线检索近期的重要通知。
> 顺带把 574 个内部系统入口也收进了同一个门户。

**访问**：`http://10.127.207.71:8091` —— 只监听内网 `10.127.207.71:8091`，无公网映射。

| 路径 | 页面 |
| --- | --- |
| `/notices` | **重要通知中心（核心）** —— 归档与检索重要通知，需登录 |
| `/` | 导航中心 —— 574 个系统入口 / 16 个分组，免登录可看 4 项 |

## 核心流程

```
企微群 @机器人  ─┐
                 ├─→ 自动整理（抽关键字/摘要点） → 归档入库 → 同事检索 / 筛选 / 导出
邮件上传 / 自动 ─┘
```

1. **谁都能发**：群里 @ 一下机器人，或把邮件传到通知中心（也支持丢进服务器 `inbox/` 自动处理）
2. **自动整理**：入库时抽关键字、摘要点、重点句加粗，不用人肉摘
3. **谁都能查**：按关键字 / 分类 / 级别 / 时间范围筛选，可导出 CSV、JSON

## 为什么用它

| 以前 | 现在 |
| --- | --- |
| 重要通知散在企微群和各自邮箱，过几天就沉底 | 一处归档，按关键字 / 分类 / 时间随时可查 |
| 归档要点靠人肉摘，摘完版本还不一致 | 入库自动抽关键字、摘要点、重点句加粗，标签点击即筛选 |
| 谁发的、什么时候发的记不清 | 记录来源群、发布人、时间，可按时间范围筛 |
| 内部系统地址散在收藏夹，新人靠问 | 顺带：一个搜索框（`Ctrl+K`）全库直达，名称 / 描述 / 标签都匹配 |
| 连客户 MikroTik 要手抄 IP 到 Winbox | 顺带：点卡片直接唤起本机 Winbox 并填好地址（助手装一次，只写 `HKCU`） |

访问控制分三级可见性 —— 免登录（4 项）/ 需登录（567 项）/ 仅管理员（3 项），
再叠加查看与管理员两种角色。共用工号类入口可以收到「仅管理员」，普通工具对登录用户开放。

## 1 访问与登录

| 项 | 值 |
| --- | --- |
| 用户名 | 名字拼音（`james`、`cathy`），管理员开通 |
| 初始密码 | 找管理员要；属于 `WEAK_PASSWORDS` 的会触发页面横幅提醒 |
| 会话 | `SESSION_TTL_HOURS=720`（30 天） |
| 权限 | `viewer`（浏览/搜索/导出）· `admin`（+ 增删改、账号、导入） |

- 未登录只能看到 `visible_to=guest` 的 **4 项**（总数 574）。绝大多数内容需登录。
- 改密码会使**其它设备上的会话立即失效**。
- 登录页「记住账号」只存用户名；密码交给浏览器密码管理器，系统不自建凭据库。

## 2 导航中心

**16 个分组**，最大一组「客户Forti站点登录方式」**275 项**、「Winbox 客户登录」**142 项**——不要翻，直接搜。

搜索匹配 **名称 / 描述 / 标签**：

| 快捷键 | 行为 |
| --- | --- |
| `/` | 聚焦搜索框（门户页则打开快速面板） |
| `Ctrl+K` | 快速打开面板，`↑↓` 选择，`Enter` 直达 |

| 卡片元素 | 含义 |
| --- | --- |
| 🟢 / 🔴 | 在线 / 离线（服务器 TCP 探测） |
| ⚪ 未探测 | 未开探测、非内网地址（防端口扫描主动跳过）、或服务器网络不通 |
| ★ | 收藏 |

单击当前页打开，中键 / `Ctrl+单击` 新标签。

**在卡片上右键**会弹出菜单：复制地址 / 在新标签打开 / 用 Winbox 打开；
管理员还会多出「编辑此项」「删除此项」，不用绕去「管理导航」里翻列表。

> ⚪ 是**服务器的视角**，不等于你的视角。通不通自己点开试。

## 3 客户站点 / Winbox 联动

这一组是 `launch=winbox` 的应用项，不是网页。**点击卡片不跳转**，而是复制设备地址并弹引导窗。

### 零安装

点卡片 → 地址已进剪贴板 → Winbox 最上方 `Connect To` 粘贴 → `Enter`。每次都要粘。
端口非 8291 写成 `IP:端口`，不带 `http://`。

### 装一次（推荐常用者）

只写 `HKCU` + `%LOCALAPPDATA%\notice-hub\`，**无需管理员权限**。

1. 头像菜单 → **Winbox 本地联动设置**
2. 三个文件下到**同一目录**：`nh-setup.cmd`、`nh-setup.ps1`、`nh-open.ps1`
3. 双击 `nh-setup.cmd` → 自动找 Winbox，找不到弹文件选择框 → 末尾选 `Y` 自测

之后点卡片直接唤起 Winbox 并自动填地址。

```cmd
nh-setup.cmd                          :: 交互安装（先从门户拉最新 nh-open.ps1）
nh-setup.cmd "C:\Tools\winbox.exe"    :: 指定路径，无交互
nh-setup.cmd -Show                    :: 协议注册 + 版本 + winbox 路径是否失效
nh-setup.cmd -Uninstall               :: 删协议注册与配置
nh-setup.cmd -Offline                 :: 不联网，用同目录的 nh-open.ps1
```

升级 = **重跑一次 `nh-setup.cmd`**。处理程序是拷贝到本机的，不跟随服务端更新，改完服务端必须逐台重跑。

## 4 重要通知中心

左侧分类：网络变更 / 故障公告 / 安全通告 / 系统维护 / 业务通知 / 人事行政 / 未分类。
级别：`urgent`=紧急 · `important`=重要 · `normal`=普通。
筛选项：分类、级别、时间范围。导出 = **当前筛选结果** 的 CSV / JSON（右上角菜单）。

详情含：标题、分类、级别、发布人、来源（企业微信 + 群名 / Outlook）、正文、附件、关键字标签。

**在某条通知上右键**：查看详情 / 复制标题；管理员另有「编辑这条」「置顶」「删除」，
不用先点开详情再找底部按钮。
正文支持 `**加粗**`、`[文字](url)`、`![alt](url)`；附件图片给缩略图，文档给下载。

### 自动整理（规则版，不调模型）

入库时对正文跑一遍规则：抽关键字、摘【要点】编号、行动句加粗。

```
关键字：客户 / 供应商 / 变更 / 邮件 / 工单

【要点】
1. 客户：星海科技（XHKE）
2. 涉及IP：203.0.113.10
```

- 规则与页面「一键整理重点」**同一套**（`wecom-bot/polish_rules.py` 从 `public/notices.html` 逐行移植；`node wecom-bot/test_polish_parity.js` 强制两边逐字节一致）。
- **不产生「一句话」语义摘要**——规则做不到，缺摘要属正常。
- 关键字来源有两类：**业务词表**（`POLISH_LEXICON`，高区分度）和**正文里的英文/数字代号**
  （`IPsec`、`FortiGate`、`YSGJ`、`85%` 这类）。词表加词后页面与企微同时生效。
- `客户 / 供应商 / 邮件 / 工单` 这类泛词**被降权**，只在找不到更具体的词时才补位；
  `目前 / 后续 / 相关 / 公司` 这类纯噪音**直接排除**，不会再出现在标签里。
- 标签里**不再有 `待汇总`**（那是给外部模型认领的内部标记，看着像噪音，已去掉）。
- 规则只能做到「挑原文里出现过的词」，提炼不出更好的中文短语——觉得不准就右键→编辑这条手改。

## 5 通知入库

### 企业微信

群内发通知时 @ 机器人：

```
@通知归档助手 【重要通知】客户公网IP回收注意事项
```

成功回执「✅ 已归档到重要通知中心」。

| 规则 | 值 |
| --- | --- |
| @ 方式 | **必须从候选列表点选**（变蓝标签）；手打 `@名字` 企微不认 |
| 关键词 | 正文须含 `重要通知` / `紧急通知` / `割接通知`（`REQUIRE_KEYWORD=1`） |
| 提问拦截 | 「帮我查询」「查一下」「有没有」等打头且 ≤50 字的消息不归档，只回执（`SKIP_QUERIES=1`） |
| 幂等键 | 企微 `msgid` → `ext_id`，重复投递只更新 |
| 消息类型 | `text` / `mixed`（图片落盘）/ `voice`（用企微转写文本）/ `quote`（引用补归档） |
| 未命中 | 群内回执说明缺什么，不静默丢 |

### Outlook / 邮件

- 丢进服务器 `/data/notice-hub/inbox/`：systemd 路径监听即时处理 + 15 分钟兜底定时器；`.msg` 自动转 `.eml`，生成 `public/originals/` 原文页，打 `待汇总` 标签。
- 或通知中心菜单：粘贴文本 / 上传文件（`.eml` `.msg` `.txt` `.md`）。
- 去重按 `Message-ID`（邮件）/ `msgid`（企微），可重复投递。

## 6 故障排查

| 现象 | 排查 |
| --- | --- |
| 页面打不开 | 内网/VPN 是否通；协议必须 `http`、端口必须 `8091` |
| 看不到某些系统 | 未登录（`visible_to=member`，567/574） |
| 状态点全灰 | 未开探测 / 公网地址被跳过 / 服务器到那台不通。以你能否打开为准 |
| 粘了地址 Winbox 没反应 | 粘错框（要最上方 `Connect To`）、带了 `http://`、端口没写 |
| 装完联动点卡片无反应 | `nh-setup.cmd -Show`：看「协议注册」是否已注册、「处理程序」有无版本号（无版本号=旧版，重跑安装） |
| @ 了机器人没归档 | ① 是否真的点选了 @；② 正文有无关键词；③ 是否被判成提问；④ 群里有无回执（有回执说明消息已到，按回执内容处理） |
| 关键字标签不准 | 词表未覆盖，加 `POLISH_LEXICON` |

## 7 安全

- 只监听内网网卡，**不要**加公网映射。
- `SYNC_TOKEN` 等同写权限（`POST /api/ingest`），别外传。
- `public/originals/` 是邮件原文静态页，**不校验登录**，文件名带 16 位哈希。含客户资料的 URL 不要外发。
- 正文可能含客户名、IP、线路信息、共用工号——按内部资料处理。

## 8 管理操作（全部在网页上）

监控、日志、备份等服务器操作见 `README.md`，本文只讲页面操作。

### 8.1 导航项：新增 / 编辑 / 删除

入口：**导航中心 → 右上角「管理导航」**（仅管理员可见）

1. 左侧选中目标分组
2. 点底部「**新增导航项**」
3. 填表 → 点「保存」

| 字段 | 说明 |
| --- | --- |
| 名称 * | 必填，上限 60 字 |
| 地址 | 可只填 `IP:端口`，自动补 `http://` |
| 一句话描述 | 卡片副标题 |
| 分组 | 归属分组 |
| 二级分组 | 卡片上的小字标签（如站点前缀 `SZX5`） |
| 可见性 | 免登录 / 需登录 / 仅管理员 |
| 色块颜色 | 十六进制，如 `#0ea5e9` |
| 标签 | 逗号分隔，上限 10 个；搜索会匹配标签 |
| 图标文字 | 留空则取名称首字 |
| 打开方式 | 网页 / Winbox / 自定义协议 |
| 设备地址（Winbox 用） | 打开方式选 Winbox 时必填，如 `10.94.6.9` |
| 自定义协议 URL | 打开方式选「自定义协议」时用 |
| 选项 | ☑ 在线探测 · ☑ 收藏 |

- **编辑**：行内「**编辑**」按钮（点行本身没有反应）；
  或在门户卡片上**右键 → 编辑此项**，直接跳到该项的表单
- **删除**：行内「删除」（二次确认）；右键菜单里也有，红字标出
- 打开方式选 Winbox 后，点卡片不再跳转，而是复制设备地址并弹出引导窗
- 分组下的项很多时（如「客户Forti站点登录方式」275 项），列表是**固定高度可滚动**的窗口，
  表头吸顶；「新增导航项」按钮固定在工具栏右上角，不会被长列表顶到很远的地方

### 8.2 分组：新增 / 改名 / 删除

在「管理导航」左侧分组栏：

| 操作 | 方式 |
| --- | --- |
| 新增 | 分组列表下方的输入框填名称 → 点「**新增分组**」 |
| 改名 | 分组行内「**改名**」按钮 |
| 删除 | 分组行内「删除」；**会连带删除该组下所有导航项**，确认框会提示条数 |
| 排序 | 拖分组行左侧的 `⠿` 手柄，或点行内 `↑` `↓` |

分组行会显示该组条目数（如 `· 275 项`），删除前可据此核对。

### 8.3 排序导航项

两种方式，效果相同（分组排序同理）：

- **拖拽**：按住行左侧的 `⠿` 手柄上下拖
- **方向键**：行内 `↑` `↓` 按钮逐条移动

改完立即生效，刷新页面后顺序保持。

### 8.4 账号管理

入口：**导航中心 → 右上角「账号管理」**（仅管理员可见）

| 操作 | 说明 |
| --- | --- |
| 创建账号 | 填账号（建议姓名拼音，如 `james`）、角色、姓名/备注、初始密码 → 创建后弹窗可「**复制账号信息**」直接发给同事 |
| 停用 / 启用 | 停用后该账号无法登录，数据不受影响 |
| 重置密码 | 新密码**只显示一次**，关掉后看不到，忘了就再重置 |
| 删除账号 | 二次确认 |

角色只有两种：`查看`（浏览、搜索、导出、改自己密码）和 `管理员`（以上 + 本页全部操作）。

### 8.5 导入通知

入口：**通知中心 → 右上角菜单 → 导入**

三个页签：

| 页签 | 用法 |
| --- | --- |
| 粘贴文本 | 直接贴通知正文；可上传附件；点「**一键整理重点**」按规则整理（头部字段归位 + 关键字 + 要点 + 重点加粗，不做语义归纳），核对后再「开始导入」 |
| 上传文件 | 支持 `.eml` `.msg` `.txt` `.md` `.csv` `.json` `.xlsx` |
| 自动同步 | 显示 `POST /api/ingest` 接口地址与同步令牌，供外部采集器调用（令牌等同写权限，别外传） |

**去重**：有外部 ID（`ext_id` / 企微 `msgid` / 邮件 `Message-ID`）时按它去重；没有则按「来源 + 标题 + 发布时间」。重复导入只更新、不产生重复记录。

菜单里还有：**管理分类**（增删分类，填名称 + 颜色）、**数据统计**、**导出当前筛选**（CSV / JSON）、**示例数据**（载入/清除，仅影响 `ext_id` 以 `demo-` 开头的记录）。
